# Project memory template

Keep under ~150 lines. Newest decisions at top.

```markdown
# <Project>, durable context

## Active work
- Feature / ticket:
- Goal:
- Branch / area:

## Decisions (newest first)
- YYYY-MM-DD, decision, why, files

## Functional / API notes
- Endpoint / model / mock keys that matter

## Open questions
- ...

## Do not regress
- ...
```

Never write secrets, tokens, keystore paths with passwords, or `.env` values.
