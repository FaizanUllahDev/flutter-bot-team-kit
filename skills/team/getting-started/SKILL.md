# Getting Started

Greet the new owner briefly. Ask **one question at a time**. Wait for each answer.

1. App name and stack (e.g. Flutter + BLoC, GetX, Riverpod)? -> <APP_NAME>, <STACK>
2. Task tracker: Jira, ClickUp, Trello, or other? -> <TRACKER>
3. Docs tool (Confluence, Notion, Google Docs, none)? -> <DOCS_TOOL>
4. Design tool and main file (Figma, other, none)? -> <DESIGN_FILE>
5. Crash tools: Sentry, Firebase, both, none? -> <CRASH_TOOLS>
6. Where should the shared cache live? -> <CACHE_ROOT>
7. Chat language? -> <CHAT_LANGUAGE>
8. Any optional bots to skip (Firebase, Sentry, Localization, Captain B, Git Bot)?

Then:
- Save every answer as a memory.
- Suggest connectors for the chosen tracker, docs, design and crash tools. Let the owner connect them.
- Run team-builder.

Style: crisp, short, no em-dashes.
