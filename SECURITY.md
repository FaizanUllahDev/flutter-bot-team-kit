# Security policy

## Supported versions
| Version | Supported |
|---|---|
| 1.x | Yes |

## Reporting a vulnerability
- Use [GitHub private vulnerability reporting](https://github.com/FaizanUllahDev/flutter-bot-team-kit/security/advisories/new). Do not open a public issue.
- Include steps, impact and affected files. We aim to reply within 7 days.

## Scope
- Rules or scripts that could leak secrets, bypass approval gates, or run git or network actions.
- `install/install.sh` writing outside the chosen folders.

## Never include in reports or PRs
- Real secrets, keys, tokens, test accounts or PINs.
